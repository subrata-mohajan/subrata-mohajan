## Achievements and how to earn them honestly

| Achievement | What it takes | Status |
|---|---|---|
| YOLO | Merge a pull request without a review | Earned |
| Pull Shark | Merged pull requests: 2, 16, 128, 1024 for the tiers | Earned (tier 1) |
| Quickdraw | Close an issue or PR within 5 minutes of opening it | Earned |
| Starstruck | A repo with 16, 128, 512, 4096 stars | Share Bou |
| Galaxy Brain | Answers marked "accepted" in Discussions: 2, 8, 16, 32 | Create a Q&A category in Bou Discussions, answer people |
| Pair Extraordinaire | Merged commits co-authored with another person | When a contributor (e.g. Delwer) works with you |
| Public Sponsor | Sponsor someone through GitHub Sponsors | Optional, costs money |

Never farm achievements with fake issues, pull requests or accounts.
